# Farmers E-commerce Website

## Overview
The **Farmers E-commerce Website** is a fully functional online marketplace designed to help farmers buy and sell agricultural products. The platform includes essential e-commerce features such as user authentication, product search, shopping cart functionality, and order management. Built using **PHP, MySQL, JavaScript, HTML, and CSS**, the system ensures secure transactions and a user-friendly experience.

## Features
### 1. **User Authentication**
- Secure **user registration and login** with password hashing.
- **Password recovery system** using PHPMailer (SMTP-based email verification).
- Session-based authentication to restrict unauthorized access.

### 2. **Product Management**
- Farmers can **list agricultural products** with images, descriptions, and prices.
- Users can **search and filter** products based on categories and keywords.
- Database-driven product storage with **secure MySQL queries**.

### 3. **Shopping Cart & Order Processing**
- **Add to cart** functionality with real-time updates.
- Order summary and **checkout system** for seamless transactions.
- **Stock management** to prevent overselling.

### 4. **Reviews & Ratings**
- Users can **leave reviews and ratings** after purchasing a product.
- Only verified buyers can review to ensure credibility.

### 5. **Admin Panel**
- **Admin dashboard** to manage users, products, and orders.
- Ability to **modify or delete listings** and **approve/disapprove reviews**.

### 6. **Networking & Security Features**
- Secure data transfer using **HTTPS and TCP/IP protocols**.
- **Email notifications** for password resets and order confirmations using **SMTP**.
- SQL injection prevention using **prepared statements**.

## Technologies Used
PHP: Backend logic and server-side processing

MySQL: Database management for products, users, and orders

JavaScript: Frontend interactivity (e.g., dynamic cart updates)

HTML & CSS: Structuring and styling the website

Bootstrap: Responsive design for mobile-friendly layout

PHPMailer: Email-based password recovery and notifications

XAMPP: Local server environment for development

Networking Protocols: HTTP/HTTPS for secure requests, SMTP for email, TCP/IP for database communication
